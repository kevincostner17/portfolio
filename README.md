# Kevin Costner — Cinematic Portfolio

Static portfolio adapted from the cinematic scroll engine in [Kevinbui16/kevin-bui-portfolio](https://github.com/Kevinbui16/kevin-bui-portfolio) (Lenis + GSAP + canvas orbit scrub), with **Kevin Costner** content only.

## Stack

- HTML / CSS / vanilla JS
- GSAP ScrollTrigger + Lenis
- Self-hosted orbit / builder / closer videos

## Edit content

- [`config.js`](config.js) — links + video paths
- [`index.html`](index.html) — copy, experience, projects, awards
- [`js/main.js`](js/main.js) — motion (pillar labels already set to Agentic RAG / ML / Full-Stack)

## Local

```bash
npx serve .
# or
python3 -m http.server 3000
```

## Deploy

Vercel (static) or GitHub Pages from repo root.
